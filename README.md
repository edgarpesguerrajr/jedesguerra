## 📝 Overview
This portfolio highlights my journey as a **Freelance Web Developer** and Computer Engineering graduate.  
It includes sections for **Education**, **Skills**, **Certifications**, and **Projects**, with animations and responsive layouts.

---

## ✨ Features
- **Responsive design** across mobile, tablet, and desktop.
- **Animated sections** for smooth fade-in effects.
- **Component-driven architecture** for scalability.
- **Dynamic data mapping** (Education, Skills, Certifications).
- **Interactive elements** like “Back to Top” scroll.

---

## 🛠 Tech Stack
- **Frontend**: React, Next.js, Tailwind CSS  
- **Backend**: Node.js, Express (optional for APIs)  
- **Database**: MySQL / MongoDB (for project data)  
- **Tools**: Git, GitHub, VS Code, Deployment via Vercel/Netlify
